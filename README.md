## 🚀 Projetos em destaque

### 1. Agente de triagem de vagas
**Status:** Planejado

Recebe a descrição de uma vaga e a lista de repositórios do GitHub, e devolve um score de aderência com um checklist de lacunas.

- Orquestração de LLM com saída estruturada (Pydantic)
- Cliente de LLM isolado por interface, para testar sem depender da API
- Avaliação com conjunto de casos fixo
- **Stack:** Python, pytest, GitHub API, API do Claude
- **Demo:** [LINK]

### 2. Classificador de senioridade e skills em vagas de IA
**Status:** Planejado

Pipeline de NLP que classifica vagas de IA por senioridade e skills. Começa com um baseline clássico (TF-IDF + regressão logística) e compara com embeddings. O modelo será publicado no Hugging Face com model card.

- Validação de schema dos dados e métrica mínima no conjunto de validação
- Mesmo pipeline usado em uma competição do Kaggle
- **Stack:** Python, scikit-learn, pytest, Hugging Face
- **Demo:** [LINK] · **Modelo:** [LINK]

### 3. Automação com IA para atendimento e anúncios
**Status:** Planejado

Fluxo no n8n com um agente de IA para triagem de mensagens e geração de textos. As regras de negócio ficam em Python e são testadas. Os dados são fictícios.

- **Stack:** n8n, Python, pytest
- **Demo / workflow exportado:** [LINK]
